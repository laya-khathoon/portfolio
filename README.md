# Laya Portfolio

A framework-free responsive portfolio built with HTML5, CSS3 and JavaScript.

## Pages
- Home
- About Me
- Achievements
- My Gallery
- Contact Me

## Run locally
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Customize
1. Change the text in the five HTML files.
2. Replace the SVG files in `assets/images/` with your own photos/certificates/project screenshots.
3. Change the email placeholder in `contact.html`.
4. Edit colors/layout in `css/style.css`.
5. Add a backend/email service to make contact submissions actually send messages.
